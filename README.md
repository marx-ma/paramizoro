# Un pequeño tesoro para ti ☠️💗

Una página interactiva romántica inspirada en aventuras piratas y en *One Piece*, hecha con HTML, CSS y JavaScript.

## Archivos
- `index.html`: estructura y textos de la página.
- `style.css`: colores, diseño adaptable y animaciones.
- `script.js`: interacciones, sorpresas y carta.

## Personalizar la carta
Abre `script.js` y busca el texto dentro del objeto `letter` en `index.html`. Cambia el mensaje por uno tuyo. También puedes cambiar los mensajes del objeto `notes` en `script.js`.

## Publicar con GitHub Pages
1. Crea un repositorio en GitHub, por ejemplo `tesoro-para-ti`.
2. Sube `index.html`, `style.css`, `script.js` y `README.md` a la raíz del repositorio.
3. Entra a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`, y guarda.
6. Espera a que GitHub Pages publique la página. El enlace aparecerá en esa misma sección.

La página usa emojis y formas CSS, así que no necesita descargar imágenes externas para funcionar. La tipografía personalizada usa Google Fonts; si no carga, se usarán fuentes de respaldo.


## Imagen de portada
`luffy-zoro-mar.png` es la ilustración usada en la portada. Mantén este archivo en la raíz junto a `index.html` y `style.css` para que aparezca correctamente.
